# Russian Translator

A web application that translates Russian text (including entire books) to English.
Features word-by-word translation on hover for deeper reading comprehension.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Translation: DeepL API

## Getting Started

### Prerequisites
- Node.js v20+
- MongoDB Atlas account
- DeepL API key

Still under development.
